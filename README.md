# Mi Portafolio

Portafolio personal hecho con React, Vite y Tailwind CSS.

## Instalación

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173)

## Tecnologías

- React + Vite
- Tailwind CSS
- Lucide React (iconos)

## Personalización

Todo el contenido (textos, proyectos, skills, links) está en `src/data.js`.
